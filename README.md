Решающее дерево для анализа вероятности победы в футбольном матче

Проект использует `European Soccer Database` (`database.sqlite`) и строит трехклассовую модель:

- `HOME_WIN` — победа хозяев;
- `DRAW` — ничья;
- `AWAY_WIN` — победа гостей.

## Главное методическое решение

Признаки каждого матча вычисляются **до добавления результата этого матча в историю**. Это предотвращает утечку целевой
переменной. В модель не передаются итоговые голы текущего матча, события матча или иные сведения, неизвестные до начала
игры.

## Используемые признаки

Для хозяев и гостей отдельно рассчитываются:

1. доля набранных очков за последние 5 матчей;
2. доля побед за последние 5 матчей;
3. среднее число забитых голов за последние 5 матчей;
4. среднее число пропущенных голов за последние 5 матчей;
5. средние очки за матч в текущем сезоне;
6. доля побед в текущем сезоне;
7. средние забитые голы в текущем сезоне;
8. средние пропущенные голы в текущем сезоне;
9. число сыгранных матчей текущего сезона.

Всего: 18 числовых признаков.

## Разделение данных

Обучение: сезоны 2008/09–2014/15.
Тест: сезон 2015/16.

Такое разделение имитирует реальную ситуацию: модель обучается на прошлом и проверяется на более позднем периоде.

## Установка
```bat
py -3.10 -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## Запуск подготовки данных

```bat
python main.py prepare
```

Создаст:

`data/prepared_matches.csv`

## Обучение модели

```bat
python main.py train
```

Будут созданы:

- `models/decision_tree.joblib` — обученная модель;
- `reports/metrics.json` — основные метрики;
- `reports/classification_report.txt` — precision, recall, F1;
- `reports/confusion_matrix.csv` — матрица ошибок;
- `reports/feature_importance.csv` — важность признаков;
- `reports/test_predictions.csv` — прогнозы тестовой выборки;
- `reports/figures/decision_tree.png` — визуализация дерева;
- `reports/figures/feature_importance.png` — диаграмма важности признаков.

## Прогноз из командной строки

После обучения:

```bat
python main.py predict --home "FC Barcelona" --away "Real Madrid CF"
```

## Графический интерфейс

```bat
streamlit run app.py
```

Откроется веб-интерфейс, где можно выбрать хозяев и гостей и получить три вероятности.
